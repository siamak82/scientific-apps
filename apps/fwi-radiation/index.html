Equations, conventions & limitations +

A point-scatterer experiment

Homogeneous, isotropic background; single scattering; homogeneous plane waves with real propagation directions and complex scalar slownesses when attenuation is enabled. θ is the angle between propagation directions (0° forward, 180° backscatter). The outward-ray opening angle is π−θ; PP reflection at incidence i uses θ=π−2i, and converted reflection uses θ=π−i−j. At fixed Vp, the acoustic density column vanishes at θ=0. SV polarizations rotate in the scattering plane; SH is perpendicular. Acoustic curves use the longitudinal displacement-equivalent kernel, whose parameter dependence is equivalent to the scalar pressure Born pattern up to common mode factors.

B = [δρ (eₒ·eᵢ) − κ (δλ* A + δμ* D)] / ρ
κ = ρ / [√Mᵢ* √Mₒ*] = kᵢ kₒ / ω²
Mᵢ*, Mₒ* = M* for P, μ* for S; κ = 1/(vᵢvₒ) when lossless
A = (eₒ·nₒ)(nᵢ·eᵢ)
D = (eₒ·eᵢ)(nₒ·nᵢ) + (eₒ·nᵢ)(nₒ·eᵢ)
M = ρ Vp²,  μ = ρ Vs²,  λ = M − 2μ,  K = M − 4μ/3
Hᵢⱼ = Σθ,mode wθ wm Re[conj(Bᵢ) Bⱼ]
Cᵢⱼ = Hᵢⱼ / √(Hᵢᵢ Hⱼⱼ)

Log-parameter columns represent derivatives per unit δ ln p; attenuation columns use either δ ln Q = 1 or δq = 0.01, q = Q⁻¹, as selected. Since dq/d ln Q = −1/Q, these coordinates have opposite signs and different scales. Ip = ρVp and Is = ρVs. Change of parameterization holds the other displayed parameters fixed. For moduli, K and μ are reference elastic moduli; attenuation parameters are held fixed when differentiating them, so their complex parts change consistently. Acoustic bases include (Vp,ρ), (Ip,ρ), (Vp,Ip), (K,ρ), (K,Vp), and (K,Ip). The elastic velocity–impedance bases are (Vp,Vs,Ip) and (Vp,Vs,Is): density is derived from the selected impedance and velocity. Vp, Vs, Ip, Is, and ρ cannot all be independent because Ip = ρVp and Is = ρVs. The velocity–Q and impedance–Q bases hold density fixed; density is omitted from the inversion variables but remains a background setting.

Visco model

e^(−iωt) convention
L(f) = (2/π) ln(f/fref) − i
M*(f) = M [1 + qP L(f)]
μ*(f) = μ [1 + qS L(f)]

A first-order, low-loss constant-Q approximation over a limited band (Q ≥ 20). Vp and Vs define reference elastic moduli, not exact complex phase velocities. Complex scalar wavenumbers are used consistently with the complex background moduli. Polarizations are real for the homogeneous isotropic waves modeled here. Boundary-generated inhomogeneous waves and path attenuation are excluded. P–SH and SV–SH scattering vanish for the isotropic point-scatterer model. Modulus Qp/Qs here refer to M and μ. Elastic inputs must satisfy M/Qp ≥ 4μ/(3Qs), so that the bulk loss is passive; invalid backgrounds are rejected. The app retains Qp/Qs coordinates rather than changing the parameter basis to bulk/shear Q. This is an educational local sensitivity model, not a complete viscoelastic forward solver.

At f = fref, velocity and attenuation can share a magnitude shape while lying in near-quadrature. With this linearized modulus model and complex kinematics, the Q kernel has a small real component of order Q⁻²; it is not asserted to be exactly imaginary. An exact constant-Q constitutive model would require its own derivatives. Magnitude-only correlation discards this distinction. Broadband phase, source uncertainty, geometry, noise, and propagation can change the actual trade-offs. The matrix defaults to the plotted mode. Optional stacking uses either outgoing-modulus displacement weights |Mref/M*out|² or explicitly equalized kernels. The displacement option assumes equal incident displacement amplitudes, with source, receiver-component and path factors omitted. It is not a survey-calibrated Hessian. The angular measure is selectable: uniform dθ for an angular section, or sinθ dθ for a 3-D solid-angle integral. In visco media these weights depend on the complex outgoing modulus. All calculations are at one frequency. N/A marks a zero-sensitivity column, not a resolved parameter.
